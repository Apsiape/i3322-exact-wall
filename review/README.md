# Independent frontier-model review

This directory records the pre-release adversarial review of the prospective
v1.3 quantitative dimension theorem.  It is intentionally separate from the
proof certificate: reviewers may test the certificate, but their verdicts are
not themselves proof inputs.

The review has three procedurally isolated model lanes:

1. public quantifiers, normalization, and asymptotic inversion;
2. the complete packet/discard proof of the universal lower bound; and
3. certificate independence, custody, and scientific claim boundaries.

Each reviewer received only the standalone repository and its assigned attack
surface.  Reviewers worked read-only and did not see the other reports before
submitting their own.  This is the project's accepted substitute for human
referee access; it is not claimed to remove model-family correlation.

See `MODEL-REVIEW-PROTOCOL.md` for the adjudication rule, `model-audits/` for
the three lane reports, `LOCALIZATION-NO-GO.md` for the decisive reconstruction,
and `ADJUDICATION.md` for the reproduced findings and current release decision.
