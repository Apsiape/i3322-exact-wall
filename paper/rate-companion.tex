\noindent\textbf{This note has been folded into the main paper.} The
dimension-complexity result it stated and proved ---
$D(\eps)=\Theta(\log(1/\eps))$ for the $I_{3322}$ quantum value, with the
explicit derived constant $23.9010650$ on the upper half --- now appears,
with the same content and the same certificate anchors, as
Section~5 of
\begin{quote}
S.~Douglas, \emph{The $I_{3322}$ quantum value is attained spatially but
not in finite dimension}, \texttt{paper/resolution.tex} /
\texttt{paper/resolution.pdf} in this repository.
\end{quote}

\noindent The certificates are unchanged and remain at
\texttt{certificate/production/rate-theta-log/} (the sealed lower-bound
chain \texttt{lower-v28\_1-bundle/} and the upper-bound bundle
\texttt{upper-U1G-bundle/}), together with their complete audit records.
The standalone version of this note is preserved verbatim in the frozen
v3.3.0 release of this repository, archived at DOI
\href{https://doi.org/10.5281/zenodo.21843326}{10.5281/zenodo.21843326}
(whose Zenodo metadata carries a stale ``3.2.3'' version string from the
metadata file shipped at tag time; its archive is the v3.3.0 tree).

\medskip
\noindent\emph{Why the merge:} the rate result is the quantitative
completion of the main paper's nonattainment theorem, and keeping the two
statements in separate documents produced avoidable drift between them.
One paper, one set of claims, one citation.
