# Pre-registration: transport without atom-spacing

The output descent may not use total variation on moving atoms: two Dirac
masses a distance `delta` apart have total-variation distance two for every
`delta>0`.  Register two tests before introducing a replacement:

1. for two decreasing response lists fed by the same ordered weighted
   source, the monotone horizontal transport cost must equal the sourcewise
   displacement exactly, with no spectral-spacing hypothesis;
2. ordinary Wasserstein transport must be attacked by a two-fibre vertical
   swap.  If it can erase a fixed vertical mismatch at arbitrarily small
   horizontal cost, the replacement must retain ordered-fibre provenance.

The positive target is the lexicographic monotone-fibre transport: first
match horizontal quantiles, then match vertical conditionals inside each
matched tranche.  No claim is permitted that the existing response receipts
already control this stronger transport.
