# Pre-registration: one-sided prefix recovery must not amplify cut flux

The finite-band assembly risks multiplying the lower boundary flux by the
number of occupied order fibres.  Register a sharper target before building
an engine.

Let a finite positive event measure carry an ordered fibre, a vertical
coordinate `zeta`, and two shifts `p,q in [-B,B]`.  Fix the upper-tail core

```text
zeta>=-L
```

and integrate shifted-tail differences only over cut coordinates

```text
ell<=L.
```

On a sector where each fibre has one sign of `p-q` and `|p-q|>=g`, the full
vertical bill of core events should be recoverable from cumulative ordered
prefixes with three separate losses:

1. horizontally large core mass;
2. address-discarded core mass; and
3. the two response fluxes through the single cut `-L`.

The flux coefficient must be independent of the number of fibres.  The
reason to test is exact: a non-core event contributes at some `ell<=L` only
if at least one shifted copy crosses into the core, while a core event loses
translation area above `L` only if a shifted copy crosses out.

The registered theorem dies if either exterior contamination or truncated
core area requires an unrecorded shell mass, or if prefix recovery forces the
flux term to acquire the fibre-count factor.
